## 凭据修复的验证范围

结果：**fixed（当前源码）**。安全不变量是：未配置完整运行时凭据时不发送登录请求；配置后凭据仅发往固定 HTTPS 登录端点且不跟随重定向；失败不阻断公共目录或泄露凭据。

相关路径为 `server/routes/paasV2.js`、`server/utils/coverDownload.js`、`.dev.vars.example` 及目录/封面回归测试。
定向测试验证缺失凭据、登录失败、空 token、超时、正常增强和缓存降级。独立只读复核指出 R2 等待未响应取消，已增加与 deadline 竞速并补回归。
R2 底层操作本身没有取消参数，超时后调用方会停止等待并降级。

原固定值可能仍存在于旧 Git 历史或恢复备份，本轮未改写历史，也没有验证其是否仍有效或替用户轮换。若仍在使用，应在第三方平台更换后配置 Secrets。
